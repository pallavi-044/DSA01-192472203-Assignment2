# C++ ASSIGNMENT 2 – CO2

## Compilation
General compilation command:

`g++ -std=c++17 -Wall -Wextra filename.cpp -o program.exe`

## Assignment Tasks

### Q1 – Call by Value, Reference and Pointer
Implemented hostel fee concession using call by value, reference and pointer. Compared how each method affects the original fee.

### Q2 – Return by Reference and Its Dangers
Implemented functions to return references and examined dangling references, const references and value copies.

### Q3 – Default Arguments and Function Overloading
Developed courier charge functions using overloaded functions and default arguments. Tested different argument types.

### Q4 – Specifying a Class with an Array Inside It
Developed a SavingsAccount class with deposit, withdrawal and mini-statement operations using an internal transaction array.

### Q5 – Static Members and Arrays of Objects
Implemented a BusTicket class using static data members, static member functions and an array of objects.

### Q6 – Friend Functions and Inline Functions
Implemented time comparison using friend functions and measured inline and non-inline execution times.

### Q7 – Diagnose, Redesign and Validate
Redesigned the Q4 transaction storage using a circular array. Compared the original and redesigned implementations.

## Conclusion

This assignment provided practical experience with C++ functions, references, pointers, classes, arrays, static members, friend functions and inline functions. The final redesign demonstrated how a circular array can improve transaction insertion efficiency.
